# DevOps Bash Automation Lab
health-check automation is under development.
## Purpose
This project contains Bash scripts for basic DevOps automation.

## Scripts
- hello.sh: Basic Bash practice.
- greet.sh: Command-line argument handling.
- health-check.sh: Checks application availability.
- service-check.sh: Checks service status.

## Validation
Bash syntax can be validated using:

bash -n health-check.sh
